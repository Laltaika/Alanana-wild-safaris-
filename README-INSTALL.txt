ALANANA WILD SAFARIS FINANCE MANAGER — FREE OFFLINE PWA

This folder contains the complete installable web app. It is NOT an Android APK or iPhone App Store application.

HOW TO PUBLISH FOR FREE (recommended: GitHub Pages)
1. Create a free GitHub account at https://github.com
2. Create a new PUBLIC repository (e.g. alanana-finance-app).
3. Upload all files from this folder (not the ZIP itself) to the root of the repository.
4. Go to repository Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.
5. After publishing, open https://YOUR-USERNAME.github.io/alanana-finance-app/ on your phone.
6. Note: a public repo makes the app's CODE public, but your personal records are saved only in your own browser storage, not uploaded to GitHub. Never put private records or backups in the repository.

IPHONE INSTALL
1. Open the published HTTPS address in Safari (not an in-app browser).
2. Tap Share > Add to Home Screen > Add. On some iOS versions use Share > More > Add to Home Screen.
3. Launch Alanana Finance from your Home Screen.

ANDROID INSTALL
1. Open the published HTTPS address in Chrome.
2. Tap the browser menu > Install app or Add to Home screen.
3. Confirm installation and open the icon.

OFFLINE USE
Open the published app once with internet to cache its files. It can then work offline on that phone.

BACKUPS
Open Backup > Download JSON backup. Save it somewhere safe. To move data to another phone, send the JSON backup file to that phone and use Backup > Restore backup. Restore REPLACES all data on that phone. This is NOT automatic sync.

PDF REPORTS
Reports > select month and vehicle > PDF / Print > Print / Save as PDF. iPhone: use print preview and Share > Save to Files. This is a print-to-PDF workflow, not a direct PDF file generator.

EXCEL REPORTS
Reports > select month and vehicle > Download Excel (.xlsx). This creates a genuine XLSX with Summary, Safaris and Expenses worksheets, without an internet connection.

IMPORTANT LIMITATIONS
- Local browser storage is not a cloud backup; deleting website data, uninstalling, or losing the device may erase it.
- Use regular JSON backups. No login, cross-device sync, or automatic exchange rate lookup.
- Monthly income uses the safari START month. Monthly expenses use their actual EXPENSE dates. A safari crossing months has its full hire income in the start month.
- Use an HTTPS host for installation and service worker offline caching; opening index.html directly from Files will not install as a PWA.
